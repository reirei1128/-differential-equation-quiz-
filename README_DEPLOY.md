# 微分方程式 判定ゲーム — GitHub Pages版

## 今回の修正
回答前の問題カードには分類・分野名を一切出しません。
右上は ★1〜★5 の問題難易度だけです。
分類は回答後のフィードバックにだけ表示します。

## GitHub Pagesで無料公開
1. GitHubで新しいRepositoryを作成（例: differential-equation-quiz）。
2. このZIPの中身をすべてRepositoryのrootにアップロードしてCommit。
3. Settings → Pages。
4. Sourceを Deploy from a branch。
5. Branchを main、Folderを /(root) にしてSave。
6. 表示されたURLを開く。

## iPhone / iPad
公開URLをSafariで開く → 共有 → ホーム画面に追加。
PWA対応なのでアプリ風に起動できます。

## 保存
成績、モード、難易度、復習設定は端末内のlocalStorageに保存。
サーバー、DB、APIキー、有料サービスは不要です。
